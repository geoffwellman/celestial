### Added
- A provider-neutral repo descriptor: a repo in `workspace.yaml` may declare `forge: github|forgejo` and `host: <web host>`; its provider, host, owner/name, SSH host, web URL and API URL are derived from its url (or origin) with lookalike hosts and contradictory declarations refused. GitHub slugs and the SSH-alias rewrite behave exactly as before.
- `lib/forge.sh`: normalised pull-request operations (view, list, checks with required checks and protection state, reviews, squash merge pinned to an expected head, current account) backed by GitHub through the workspace's own account. A repo on Forgejo is refused explicitly until that backend exists.
