### Added
- `cel-fanout replace reserve|attach` (orchestrator-only): the audited path for publishing a clean replacement of a fleet PR whose branch carried private artifacts. `reserve` fences the original (row, worker, PR number and frozen head), proves with git that the candidate is the original minus hygiene-private paths in tree *and* history, and writes a child row plus a source marker in one ledger write; `attach` verifies the worker's ready PR at exactly the reserved head. The worker is handed to the child (one slot, one owner), the original stays as evidence, no review or gate evidence carries over, and a lost response is resumed by replaying the same call. Collect, review, land, release, status, fleet and gc consume the lineage; nothing is written to GitHub.
