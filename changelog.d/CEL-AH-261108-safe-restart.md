### Fixed
- `cel run ... --restart` of an agent running in Rex, from a workspace whose `session_backend` is Herdr (the default) and without `--session-backend rex`, built its relaunch for Herdr: the OpenCode launcher went into the env prefix and the Rex launch script added its own, so the relaunch ran `node launch.mjs -- node launch.mjs -- opencode ...` and was refused (`reason=unsupported_argument`) after the agent had been stopped. A restart now builds its line for the host of the pane it replaces (Rex or Herdr), whatever the workspace default or flag says; a Herdr agent restarted from a Rex-default workspace likewise gets its launcher.
- A Rex restart no longer stops an agent whose relaunch would be refused: the relaunch's own private script (same environment, same line) runs first with the OpenCode launcher in its new `--check` mode (config, location and argv admitted exactly as a launch would, nothing native started). A refusal prints its reason and leaves the agent running.
- A Rex relaunch that still dies during startup (for OpenCode: before its launcher admits the TUI) no longer leaves a dead `--keep-open` session behind: its terminal is closed once Rex reports its program finished, the launcher's refusal reason is repeated, and the restart exits non-zero with the exact `cel run` line that brings the agent back.
- `--dry-run` of a Rex launch or restart prints the exact line the private launch script runs (env prefix with secrets masked, launcher, executable, argv) instead of the runtime and argv alone.
