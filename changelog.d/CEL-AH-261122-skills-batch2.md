### Added
- Seven more skills for every agent, vendored into `core/skills/` and linked into claude, omp, pi, codex and opencode: `mcp-builder`, `webapp-testing` and `anthropic-skill-creator` (anthropics/skills; upstream `skill-creator`, renamed because Codex bundles a system skill of that name) and `create-mcp-app`, `add-app-to-server`, `convert-web-app` and `migrate-oai-app` (modelcontextprotocol/ext-apps).
- Workspace-scoped skill sets: a `vendored-skills.yaml` entry with `set: <name>` lives in `core/workspace-skills/` and reaches only the agents of workspaces whose `workspace.yaml` lists that set in `skill_sets:`. `cel ws sync` (and so `cel update`) links them into `<workspace>/.cel/skills` and removes undeclared ones, writing nothing into a repo; every `cel run` launch for the workspace names that directory (agents.yaml `workspace_skills`: claude `--add-dir`, omp `--plugin-dir`, pi `--skill`, OpenCode `OPENCODE_CONFIG`; Codex links them disabled in a marked `config.toml` block and a launch enables its workspace's with `-c skills.config=[...]`). Reviewers get their workspace's too.
- The `cloudflare` set (`workers-best-practices`, `durable-objects`, `wrangler`, `agents-sdk`, `workers-profiling`, `web-perf`) and the `expo` set (`expo-router`, `expo-ui`, `expo-native-ui`, `expo-animation`, `expo-dev-client`, `expo-upgrade`, `eas-workflows`, `eas-app-stores`).
- Skills whose upstream text has an agent deploy, publish, submit to an app store, spend money or run paid builds/generation (`mcp-builder`, `anthropic-skill-creator`, `workers-best-practices`, `durable-objects`, `wrangler`, `agents-sdk`, `workers-profiling`, `expo-native-ui`, `expo-dev-client`, `eas-workflows`, `eas-app-stores`) open with a recorded patch note: under celestial rules those steps wait for the owner's approval.
- hygiene: `BY-4` (the SPDX `CC-BY-4.0` licence id in upstream licence text) is a standard token, not a ticket.
