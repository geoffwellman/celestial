### Added
- omp can now route through the cel gateway (CLIProxyAPI). Set `gateway.omp_exclude` to name the accounts omp must never use (the personal account), then run `cel gateway omp-scope --apply`. That tags every other claude account with prefix `omp` through the management API; `--check` verifies the tags. A `via: gateway` omp profile then runs `celgw/omp/<claude-model>` from a `celgw` provider written to omp's `models.yml`, using the CLIProxyAPI api-key (no more retired broker token), an `x-session-id` header and the profile's thinking level. It fails closed: with no exclusion, or with an excluded account prefixed, the route is refused. Other clients never see `omp/` ids. Fixed: gateway panes launched without an explicit session id exported an empty `CEL_SESSION_ID`. A no-spend real-binary proof is in `tests/live/omp-gateway.sh`.
