### Added
- `cel forge run list <repo> [--branch b] [--limit N]`, `cel forge run view <repo> <run-id>` (the run and its jobs) and `cel forge run logs <repo> <job-id> [--tail N] [--raw]`: read-only CI for every role on Forgejo (Actions over its API, no web login and no token in the agent's hands) and GitHub (`gh run`). Run and job states are success · failure · cancelled · skipped · running · queued (Forgejo's `status: failure` with a null `conclusion` is a failure); `logs` drops per-line timestamps (and GitHub's job/step columns) unless `--raw`, and on GitHub shows the job's failed steps.
- `cel forge pr close <repo>#<n> [--comment-file f]` (the comment posted first, the branch never deleted) and `cel forge pr ready <repo>#<n>` (Forgejo: the `WIP:` / `[WIP]` title prefix removed; GitHub: `gh pr ready`; a no-op on a PR that is not a draft), so a Forgejo PR opened as a draft can be landed. The product's own agent (solo, orchestrator) may change only its workspace account's PRs or a migrated Forgejo PR (author `Ghost`) - anything else is refused with the author's name; the owner may change any; core, root, team members and reviewers are refused.

### Changed
- The box-wide budget counts helpers only: `budget.max_live_agents` (default 8) now holds reviewers, team members and other launched agents. Product agents (`*-orch`, solo lanes) and core/root are shown by `cel budget` but never counted, so a box running ten products no longer refuses every reviewer. `budget.max_team_members` (4) and the memory floor are unchanged; `cel budget --json` adds `live.helpers`.
- Forgejo `mergeable: false` reads `unknown`, never `conflicting`: Forgejo also answers false before it has (re)computed a PR - recorded live on a clean fast-forward - and its API has no field that proves a conflict. `cel solo land` and the ready-to-land list do not treat unknown as a conflict.
- A Forgejo Actions commit status's site-relative `target_url` is made absolute in `cel forge pr checks`.
- The Forgejo test fixtures are re-recorded GET-only from Forgejo 17.0.1 and anonymised (tests/fixtures/forge/forgejo/PROVENANCE says per file what was recorded and what is still spec-derived); new recorded fixtures cover migrated PRs and reviews (author Ghost, no commit), Actions statuses, runs, jobs and a job log, and GitHub's `gh run list|view` and a failed job's log.

### Security
- The guard refuses every agent that sources `lib/forge.sh` or calls its `_forge_*`/`forge_*` functions (also inside `bash -c` or `$(...)`): they carry the forge token with none of `cel forge`'s guard and authorship checks. Use `cel forge`. A tripwire like the rest, not a sandbox.
