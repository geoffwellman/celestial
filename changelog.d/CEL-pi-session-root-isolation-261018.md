### Fixed
- Pi workers no longer lose their session writes when an OMP starts. Launches pin `PI_CODING_AGENT_DIR` to the launched runtime's own agent root (Pi `~/.pi/agent`, OMP `~/.omp/agent`) instead of forwarding the pane's ambient value (which #168 did, and a leaked OMP root made OMP's startup migration rename live Pi session directories). A custom Pi-only root is now `CEL_PI_AGENT_DIR`; an inherited `PI_CODING_AGENT_DIR` is ignored. Overlapping Pi/OMP roots (equal, symlink alias, nested) refuse the launch and fail `cel doctor`. Gateway token and `CEL_SESSION_ID` are `env` words on the launch line, no longer exported into the pane shell. Prevention only: existing sessions are not repaired or migrated.
