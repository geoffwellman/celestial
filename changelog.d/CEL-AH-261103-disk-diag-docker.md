### Added
- `cel box diag`: at most two bounded lines for a disk alert to append. The first is docker's own images / build cache / volumes summary, left out silently when docker is absent, not this user's to query, or slower than `CEL_BOX_DIAG_TIMEOUT` seconds (default 30). The second names every running `docker build` / `buildx build|bake` (five at most, argv cut to 120 characters, `+N more` for the rest) with the agent that owns it - from the HERDR_PANE_ID or REX_SESSION/REX_BLOCK its process tree inherited, or, marked `(by cwd)`, the agent whose working directory contains the build's. Build argv is redacted before it is printed: values of `--build-arg`, `--secret`, `-e`/`--env` (spaced or `=` form) and every bare `KEY=VALUE` become `***`, keeping the key. The herdr roster lookup is held to the same time limit; a herdr that hangs leaves the build named by its pane (`agent=? pane=<id>`).
