### Fixed
- Rex reviewer retirement works for a repo on Forgejo. `lib/reviewer-retirement.sh` resolved the repo with `ws_repo_github_slug`, which has no answer for a Forgejo url, so `tools/reviewers/retire.mjs` got an empty slug and `cel gc` reported `native reviewer retirement incomplete ...: invalid_workspace_arguments` every tick for such a repo's reviewers. The repo's forge and owner/name now come from `forge_repo`, and a Forgejo repo's PR state is read with `cel forge pr view` as the workspace (never from GitHub, whose mirror numbers other PRs the same); the answer must name exactly that owner/name and PR. Every other proof is unchanged, a GitHub repo is still read with gh, and an unresolved or malformed slug, or a forge other than github or forgejo, is still refused.
