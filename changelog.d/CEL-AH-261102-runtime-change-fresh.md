### Fixed
- `cel run ... --restart` onto a different runtime (for example an omp solo lane restarted with `--profile opus`, which runs Claude) no longer plans to resume the old runtime's session into the new one: it starts fresh, says which runtime the agent last ran on, and leaves that session on disk. The last-session map now records the runtime with each session (`{session, runtime}`; older bare entries are still read), so a relaunch over a dead agent follows the same rule. Switching onto OpenCode still refuses until an explicit `--fresh --handoff` migration.
- Session capture ignores omp task-subagent transcripts. omp runs subagents inside the agent's own process, so its hook reported a subagent's file (`<session>/<Task>.jsonl`, beside the session's own `<session>.jsonl`) and the Rex receipt recorded it as the lane's session; a subagent's turns no longer change the receipt's session, its idle/working state, or the last-session map. A receipt that already captured one resumes the parent session instead.
