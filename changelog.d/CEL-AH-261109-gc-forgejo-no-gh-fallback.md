### Fixed
- `cel gc` never asks GitHub about a Herdr reviewer's PR by the bare repo name any more. A repo whose workspace cannot be found, or whose forge `forge_repo` cannot resolve (a declared `forge: forgejo` whose lookup fails, an undeclared non-GitHub url), fell through to `gh pr view <n> --repo <name>`, which reaches the GitHub account's same-named repo - for a repo that moved to Forgejo, its old mirror, whose PR numbers differ - so a merged mirror PR could close the reviewer of an open Forgejo PR. Such a reviewer is now UNKNOWN (kept). A GitHub repo is asked by the owner/name its workspace declares (or its clone's origin), a Forgejo repo of Forgejo, and nothing else is asked at all.
