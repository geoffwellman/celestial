### Fixed
- The "mise hung here" record behind the bounded shim check (#342) was a fixed-name file in `$TMPDIR` (`cel-shim-hung.<pid>.<start>`). Celestial read and appended to it without checking that the file was its own or that it was not a symlink. On a shared `/tmp`, another user could create it first, either to fake a hang or to turn the append into a write somewhere else.
  - The record now lives in a directory of the command's own, made with `mktemp -d` (mode 0700, unguessable name). That directory is under `$XDG_RUNTIME_DIR` when it is a directory this user owns, and under `$TMPDIR` otherwise.
  - Before every read and append, the directory must still belong to this user and not be a symlink, and the record file must not be a symlink. If that check fails, nothing is read or written and the check answers "cannot tell".
  - Only a command's top-level shell opens the directory, so the `$(...)` subshells it runs share it. `cel doctor`, `cel setup` and `cel update` open it up front. Because the opening shell is top-level, the directory name now carries that shell's own PID.
  - The directory is removed when that shell exits, through an EXIT trap chained ahead of any trap the shell already had. A record left by a shell that died is removed by the next open, and so are old fixed-name records that are plain files of this user's. Symlinks are never followed or removed.
