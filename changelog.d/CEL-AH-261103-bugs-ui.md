### Fixed
- `cel drive` and the dashboard's orchestrator room no longer corrupt text when a multi-byte character (an emoji, an accented letter) lands across two polls of the session file: the tailer keeps the partial character until its last byte arrives instead of decoding each read on its own into replacement characters.
- `cel preview`'s localhost forward no longer takes 127.0.0.1:<port> when the app never answered on the tailnet address: it says so in the preview's journal and exits, instead of accepting clients it could only drop. Each readiness probe is bounded too, so an address that silently drops connections cannot stall it.
- The pages server answers a malformed or non-object JSON body on `/api/feedback`, `/api/promote` and `/api/revoke` with 400 rather than a server 500; an oversized body stays 413.
- Reader feedback on the pages server is accepted only for a published document (a flat, non-dot, regular file); a made-up name is 404 and leaves no receipt and prompts no pane.
- The dashboard's upstream cache runs one read per key at a time - a burst of `/svc/` proxy requests now runs `cel services` once, not once per request - and a failed read (herdr, gh, `cel services`, `cel decide`, `cel quota`, Linear) no longer replaces the last good answer with an empty one: the proxy keeps its known ports, and "mine", PRs, agents and decisions do not blank out for the cache's lifetime after one hiccup.
- The dashboard names orchestrators by the alias `cel_alias_norm` gives them, asked of the shell rule rather than a JavaScript copy: messaging an orchestrator whose repo or product name is not already an alias (`Gadget.App` -> `gadget-app-orch`), or a solo product's agent, is no longer refused as an unknown recipient.
