### Changed
- `cel solo land` now says which agent landed a PR. The forge shows every land as merged by the workspace's account (the owner's token), so the squash message now ends in git trailers: `Reviewed-by:` for the recorded verdict's reviewer, each approving forge account and each required extra reviewer, then `Landed-by: <agent alias> (cel solo land)` and the `Gate:` line. The review note, if any, moves to its own paragraph above the trailers. Just before the merge, a comment goes on the PR: `Landing as <alias> via cel solo land: approved by <reviewer> at <sha>, checks green.` This works on both GitHub and Forgejo. The lander is the alias from the agent's launch. A person running it from their own shell is recorded as the account, `by hand`. If the comment is refused, the land reports it and still merges. New forge operation: `forge_pr_comment`.
