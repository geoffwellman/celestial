### Fixed
- An orchestrator restarted with an explicit `--model` (and `--thinking`) to keep the model its saved session already runs no longer reads as running an older launch line. The steward, `cel update` and `cel doctor` used to report `extra: --model <id>` for it after every update, because a plain restart would take the workspace default instead. The running model is read from the saved session: the later of its last `model_change` and its last assistant message's own model. Helper-model `model_usage` entries are ignored. Spellings of one model compare equal (`celgw/omp/claude-opus-5-5`, `anthropic/claude-opus-5-5` and `claude-opus-5-5`). The `--thinking` item is exempt too when it is the session's last thinking level. A `--model` the session is not running, a different thinking level, or any other extra or missing flag still alerts. A cached verdict that relied on the session is re-checked when the session switches model.
- The steward's older-launch-line alert is said once per change, not once per build. An agent whose difference is unchanged is no longer raised again after each `cel update`; a new difference for that agent is raised once.
