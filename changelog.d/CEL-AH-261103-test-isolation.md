### Fixed
- The test suite no longer reads or writes the box's own state. With AFK switched on box-wide, release tests failed locally with "afk: dispatch waits" because `lib/afk.sh` read the real `~/.local/share/cel/afk/state.json`, while CI stayed green. Box state now honours the XDG base directories - AFK, inbox, registry, config, gateway, pages, quota, update, steward, liveness, build-slot, gc and reviewer records, caches, `cel-verify` artifacts, and the dashboard and console readers - defaulting to `~/.local/share/cel`, `~/.local/state/cel` and `~/.cache/cel` exactly as before when `XDG_*_HOME` is unset. `tests/run.sh` gives every test its own private `XDG_DATA_HOME`, `XDG_STATE_HOME`, `XDG_CACHE_HOME` and `XDG_CONFIG_HOME` under the run's temporary directory (a test that sets one itself still wins) and keeps `HOME` real. The tools tests run still resolve as before: mise's directories are pinned so the `node` and `bun` shims work, and herdr's socket is linked into each private config home.
