### Added
- `cel-fanout request-review <id> --head <full-sha>` requests the workspace's configured external reviewer (`policy.reviewer`) on a fleet-owned PR, through the workspace's own GitHub account. It refuses unless the ledger review is approved with explicit-head provenance for exactly that head, the PR is this fleet's open non-draft PR, and the PR head and the remote branch both equal `--head`; it adds only that reviewer, verifies `requested_reviewers`, and writes nothing else. Raw `gh pr edit` stays guard-refused. `--dry-run` checks without requesting. Usable once `review` records `head_source: explicit`.
