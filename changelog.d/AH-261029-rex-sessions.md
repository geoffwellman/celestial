### Added
- `cel run ... --session-backend rex` opens a named Rex session instead of a Herdr pane, independent of the agent runtime/model/profile. Herdr remains the default; workspace `session_backend: rex` selects Rex for new launches. Existing sessions keep their terminal host on restart. Role, gateway and inbox setup are reused, and `cel sessions [--json]` inventories both backends. Native pi/OMP hooks report turn state and conversation identity; unknown runtime state stays busy and an unreported conversation cannot be silently discarded on restart. Managed Rex agents participate in duplicate prevention and inbox discovery; automatic Herdr cleanup never closes their terminals or removes live checkouts.
