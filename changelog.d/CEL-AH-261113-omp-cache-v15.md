### Fixed
- Pi and OpenCode gateway catalogs read OMP 18.16's version-15 `models.db` model cache again. Before this fix, every newly published model (for example `claude-fable-5-2`) was registered with no context window, output limit or thinking, so Pi fell back to its 128K/16K/no-thinking defaults. The accepted cache versions (13, 14, 15) now live in one module, `tools/omp-model-cache.mjs`, which both readers import. Version 15 marks non-chat models with `kind` rather than `type`, and the readers now accept either. An unknown version is still refused, and the error now names that version and the versions this release reads.
- When capability enrichment fails, the failure is now reported instead of silent. `cel gateway pi-models`, `cel gateway refresh` and the launch-time Pi model write print a warning that names the cause; the launch still proceeds. `pi-models --json` reports this in `.enrichment`. `cel doctor` reports when enrichment is unavailable and lists any published Claude/Codex chat ID in Pi's `models.json` that has no `contextWindow`. `cel gateway pi-models --refresh` replaces such a bare entry with the enriched one.
