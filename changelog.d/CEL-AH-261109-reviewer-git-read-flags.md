- Reviewers' git read verbs no longer take the flags that write a file, run a program or pager, or change config: `--output`, `--ext-diff`, `--textconv`, `cat-file --filters`, `grep -O`/`--open-files-in-pager`, `--show-signature`, global `-p`/`--paginate`, `--help` and `git help <topic>`, `fetch --upload-pack` and `--set-upstream`, in every spelling (separate or attached argument, quoted, abbreviated, clustered short options). `git diff`, `log -p`, `show`, `range-diff` and `grep` stay allowed.
