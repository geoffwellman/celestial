- Reviewers' git read verbs no longer take the flags that write a file, run a program or pager, or change config: `--output`, `--ext-diff`, `--textconv`, `cat-file --filters`, `grep -O`/`--open-files-in-pager`, `--show-signature`, global `-p`/`--paginate`, `--help` and `git help <topic>`, `fetch --upload-pack`, `--set-upstream` and `--recurse-submodules`, in every spelling (separate or attached argument, quoted, abbreviated, clustered short options). `git diff`, `log -p`, `show`, `range-diff` and `grep` stay allowed.
- A reviewer's git command is taken literally: `$`, backquotes, brace expansion and unquoted globs before `--` are refused, as are `VAR=` and `env`/`command`/`exec`/`sudo` in front of git, setting, exporting or unsetting any `GIT_*` or `PAGER` variable, `--git-dir`, `--work-tree`, `--namespace`, and `-C` to anywhere but the reviewer's own checkout (`CEL_REVIEW_CHECKOUT`, set at launch).
- A reviewer's launch pins git's environment: `GIT_EXTERNAL_DIFF`, `GIT_SSH`, `GIT_SSH_COMMAND`, `GIT_PROXY_COMMAND`, `GIT_EXEC_PATH`, `GIT_DIR`, `GIT_WORK_TREE`, `GIT_NAMESPACE`, `GIT_CONFIG_PARAMETERS` and `GIT_CONFIG` unset, `GIT_PAGER`/`PAGER` `cat`, and environment config `safe.bareRepository=explicit`, `core.fsmonitor=false`, `core.pager=cat` - a bare-repository-shaped directory a PR commits is no longer read as a repository when the reviewer stands in it.
- Output redirects stay allowed for reviewers: the guard keeps them from git and forge writes, not from writing notes.
