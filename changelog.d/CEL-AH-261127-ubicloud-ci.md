### Changed
- CI and the release workflow run on Ubicloud's GitHub Actions runners (`ubicloud-standard-2`: Ubuntu 24.04 x64, 2 vCPU, 8 GB) instead of GitHub's `ubuntu-24.04`. Job and check names are unchanged, so the required "Tests and publication hygiene" check still gates `main`. The runner image is built from GitHub's own runner-images templates, so the setup steps are unchanged. Jobs need the Ubicloud GitHub app installed with access to this repository; without it they queue with no runner.
- The suite's parallel pool follows `nproc`, so on these runners it runs two files at a time. The regression suite takes about 23-25 minutes there, against 13-14 on GitHub's 4-vCPU runner, so its job time limit rises from 30 to 45 minutes.
