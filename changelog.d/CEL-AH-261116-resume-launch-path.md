### Fixed
- An agent's PATH no longer depends on who launched it. Agents the steward resumed after a Rex restart or managed rex upgrade came back without `$CEL_ROOT/bin` (the steward is a systemd unit that never reads the owner's rc and its `cel shellenv`), so plain `cel` was "command not found" in their shells. Every launch line (`_run_launch_env`: `cel run`, `--restart`, `cel core`, the steward's resume and auto-start, Herdr and Rex alike) now starts the runtime through one step that puts `$CEL_ROOT/bin` and the Linear skill bin first, keeps the PATH it would otherwise have had in its own order, and appends mise shims (when present) and `~/.local/bin` only if that PATH lacks them - each directory once. Agents already running keep their old PATH until their next launch.
