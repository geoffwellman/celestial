### Fixed
- The dashboard now shows every running agent, whichever terminal holds it. It used to read `herdr agent list` alone, so every Rex agent (most orchestrators, solo lanes, core and their reviewers) was missing from the Orchestrators, Working now, Today and Feature teams cards and the workspace filter, and the tagline read `3 orchestrators · 3 workspaces`. It now reads `cel sessions --json`, the Herdr and managed Rex inventory that launches, the budget and gc already use. That read is cached for 8 s and refreshed in the background, so pages never wait on it. Each fleet row says which backend holds it (`backend: herdr|rex`) and keeps its own address (a Herdr pane id or a Rex block). `/api/state` lists a workspace's Rex agents too, including a reviewer whose Rex record names the workspace.
- The "open pane" button (a Herdr pane focus) is hidden for Rex rows, and the agent drawer says "a Rex session" instead. `/api/focus` refuses a Rex address with a reason and never sends it to Herdr. Herdr rows keep the button.
- An orchestrator's room works for Rex orchestrators. `cel drive list|tail|send|receipt` read the same inventory instead of Herdr's alone. A Rex receipt's native session is used as the transcript: an absolute path directly, a Claude id under its project directory. `cel drive list --json` rows carry `backend`. Before this, a Rex orchestrator's room showed "transcript not running" and mail to it was refused as "not a running orchestrator".
