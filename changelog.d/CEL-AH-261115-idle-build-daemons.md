### Added

- The steward reports idle build-tool daemons once. A Gradle daemon or Kotlin compile daemon (found by main class, as the unledgered-server report skips them; Gradle workers are never reported) with no live child, CPU time grown less than `CEL_BUILD_DAEMON_IDLE_CPU_SECONDS` (default 2) since the previous tick, and alive more than `CEL_BUILD_DAEMON_IDLE_MIN` minutes (default 30) is reported once per pid and start time to its owner - the `CEL_INBOX_ME` of the nearest ancestor carrying it, else the daemon's own, else the agent whose directory it runs in, else root - with pid, RSS, idle minutes, cwd and how to stop it (`./gradlew --stop` in the project from a `gradlew` ancestor, or `kill <pid>`). Nothing is stopped or signalled. Per-daemon CPU samples live in the steward state (`<state>.build-daemons`), pruned of dead pids every tick.
