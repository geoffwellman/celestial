### Fixed
- Rex reviewer retirement (`tools/reviewers/retire.mjs`) recognises an inbox watcher's jq child that runs an earlier release's `_INBOX_WATCH_JQ`, not only the launch checkout's current text. Since #285 changed the program, every watcher started before the update was an `unknown_watcher_child`, so its reviewer stayed `protected` (and `cel gc` kept retrying) until its pane restarted. The known programs are listed by sha256 of their exact text in `tools/reviewers/inbox-watch-programs.mjs`, each with the release it came from (the pre-#285 one, from v0.4.0 to main before #285, and the current one); any other program is still unknown and protected. `retire.test.mjs` fails when `lib/inbox.sh`'s program changes without its hash being added there.
