# design focus: accessibility

This focus narrows the role; it never widens its authority.

- [ ] Contrast meets WCAG AA; focus is always visible.
- [ ] Everything works with the keyboard alone, in a sensible order.
- [ ] Labels and roles are present for screen readers; images have alt text or are marked decorative.
- [ ] Motion respects reduced-motion; nothing flashes.
- [ ] Text scales to 200% without loss.
