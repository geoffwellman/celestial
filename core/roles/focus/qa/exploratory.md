# qa focus: exploratory

This focus narrows the role; it never widens its authority.

- [ ] Time-box a charter per risk area named in the brief; note what you tried.
- [ ] Go off the happy path: odd input, double clicks, slow steps, two tabs.
- [ ] Look for data loss and wrong money first, cosmetics last.
- [ ] Every finding: severity, steps, evidence; separate bugs from questions.
- [ ] Close with what you did NOT cover.
