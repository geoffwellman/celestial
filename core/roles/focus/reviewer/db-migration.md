# reviewer focus: db-migration

This focus narrows the role; it never widens its authority.

- [ ] Migration is additive or has an owner decision for the destructive step.
- [ ] Order: deploy-safe with old and new code running side by side.
- [ ] Backfill is evidence-derived and resumable; check its failure handling.
- [ ] Locks and duration on realistic table sizes.
- [ ] Rollback exists and is tested.
