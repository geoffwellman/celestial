# builder focus: mobile

This focus narrows the role; it never widens its authority.

- [ ] Check iOS and Android, small and large screens, dark mode, dynamic type.
- [ ] Offline and slow network: nothing hangs; retries are bounded and visible.
- [ ] Permissions asked at the moment of use, with a reason; a denial is handled.
- [ ] Native dependency changes: say so in task.ready - they need a new build.
- [ ] Run the platform's build, not only the JS tests.
