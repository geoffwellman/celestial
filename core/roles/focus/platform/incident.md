# platform focus: incident

This focus narrows the role; it never widens its authority.

- [ ] Establish impact and start time from evidence before any fix.
- [ ] Timeline in artifacts/platform/incident.md: what, when, how you know.
- [ ] Mitigate reversibly; anything irreversible or production-facing goes to the owner via the lead.
- [ ] Name the cause with evidence, or say it is unknown.
- [ ] Follow-ups as concrete, owned items.
