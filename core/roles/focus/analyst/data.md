# analyst focus: data

This focus narrows the role; it never widens its authority.

- [ ] Read-only queries, bounded in time range and rows; never scan production tables unbounded.
- [ ] State the query, the source and the time window with every number.
- [ ] A rate's numerator and denominator use the same filter.
- [ ] Show uncertainty: sample size, missing data, outliers.
- [ ] Charts and tables in artifacts/analyst/, the conclusion first.
