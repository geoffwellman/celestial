# analyst focus: archaeology

This focus narrows the role; it never widens its authority.

- [ ] Answer from git history, PRs and tickets, with dates and commit shas.
- [ ] Search for later reversals before citing a decision.
- [ ] Separate what the code does now from what it was meant to do.
- [ ] Quote the source line for every claim; mark inference as inference.
- [ ] End with what is still unknown and where it could be found.
